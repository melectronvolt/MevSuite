Un TP avec Python

Les scripts travaillent sur les grandeurs de la séance. Les trois expériences ci-dessous peuvent aussi être exécutées chacune dans un document vide, avec les mesures fournies dans le code.

Exécuter un premier calcul

  1. Dans Mode › Expert, ouvrez Python › Nouveau script. Tapez print(14.1 / 0.30).
  2. Cliquez sur Exécuter ou appuyez sur F5. La console affiche 47.0. Ctrl + Entrée exécute également le script actif.
  3. Enregistrez la séance en .phy pour conserver le programme. Le bouton Arrêter permet d’interrompre un calcul en cours.

Utilisez un point comme séparateur décimal en Python. print écrit dans la console, mr.creer crée une grandeur de la séance et plt.show() affiche une figure. Les modules fournis fonctionnent hors connexion.

1. Retrouver la résistance d’un conducteur

Dans un document vide, créez les mesures et ajustez le modèle U = RI. L’ordre des arguments de mr.modeliser est l’ordonnée puis l’abscisse.

import mevreg as mr

mr.creer("I", [0, 0.10, 0.20, 0.30], "A")
mr.creer("U", [0, 4.7, 9.4, 14.1], "V")
mr.tableur("Mesures", ["I", "U"])
mr.graphe("Caractéristique", "I", "U")
_ajustement = mr.modeliser("U", "I", modele="lineaire", graphe="Caractéristique")
print(f"R = {_ajustement.a:.2f} Ω pour {_ajustement.n} points")

ConsoleR = 47.00 Ω pour 4 points

Si vos élèves ont déjà saisi I et U, supprimez les deux lignes mr.creer du programme pour travailler sur leurs propres valeurs. Remplacez ensuite la lecture à 0,20 A par 9,2 V dans le tableur et relancez l’ajustement. La résistance affichée devient 46,71 Ω. Retrouver la même expérience avec la souris.

2. Estimer une incertitude avec des mesures répétées

Quatre lectures indépendantes d’une même longueur sont disponibles. Une cinquième case est vide. Sélectionnez les valeurs finies avant de compter les répétitions.

import numpy as np

_longueurs = np.array([9.8, 10.0, np.nan, 10.2, 10.0])
_mesures = _longueurs[np.isfinite(_longueurs)]
_effectif = _mesures.size
_ecart_type = _mesures.std(ddof=1)
_incertitude = _ecart_type / np.sqrt(_effectif)
print(f"{_effectif} mesures, moyenne = {_mesures.mean():.2f} cm")
print(f"s = {_ecart_type:.3f} cm, u = {_incertitude:.3f} cm")

Console4 mesures, moyenne = 10.00 cms = 0.163 cm, u = 0.082 cm

ddof=1 utilise le diviseur n − 1. Il faut au moins deux valeurs finies. Pour appliquer l’exercice à une colonne de la séance, remplacez la création de _longueurs par mr.valeurs("L") après import mevreg as mr. L’unité de L doit correspondre à celle affichée dans la console.

3. Identifier la fréquence et l’amplitude d’un son

La sinusoïde de démonstration a une amplitude de 1 et une fréquence de 440 Hz. Le signal contient 2 000 échantillons régulièrement espacés à 8 000 Hz. Le spectre possède donc une graduation tous les 4 Hz.

import numpy as np
import matplotlib.pyplot as plt

_frequence_echantillonnage = 8000
_temps = np.arange(2000) / _frequence_echantillonnage
_signal = np.sin(2 * np.pi * 440 * _temps)
_effectif = _signal.size
_frequences = np.fft.rfftfreq(_effectif, d=1 / _frequence_echantillonnage)
_amplitudes = np.abs(np.fft.rfft(_signal)) / _effectif

# Seules les fréquences ayant un partenaire négatif sont doublées.
_amplitudes[1:(_effectif + 1) // 2] *= 2
_pic = np.argmax(_amplitudes)
print(f"{_frequences[_pic]:.0f} Hz, amplitude = {_amplitudes[_pic]:.2f}")

plt.plot(_frequences, _amplitudes)
plt.xlabel("Fréquence (Hz)")
plt.ylabel("Amplitude")
plt.xlim(0, 1000)
plt.show()

Console440 Hz, amplitude = 1.00

La composante continue, et celle de Nyquist lorsque l’effectif est pair, n’ont chacune qu’un terme. Le calcul respecte ces deux cas. Pour un signal acquis, vérifiez le pas de temps en secondes. Une composante continue importante peut devenir le plus grand pic. Pour rechercher une oscillation, examinez les fréquences strictement positives. Lire un spectre dans le menu Analyse.

Relier les variables au document

  • Entrées. Au début de l’exécution, chaque grandeur existante est disponible sous son nom comme tableau NumPy et chaque paramètre comme un nombre. mr.valeurs("U") relit les valeurs, y compris celles modifiées explicitement pendant le script.
  • Résultats. Une nouvelle liste ou un tableau numérique réel à une dimension, non vide et de nom public peut devenir une colonne de résultats. Un nom commençant par _ garde le calcul local. Pour choisir le nom et l’unité, écrivez mr.creer("P", U * I, "W").
  • Mesures existantes. Réaffecter U dans Python modifie la variable locale. mr.modifier("U", valeurs=...) écrit dans la grandeur. Pour une relation recalculée par le tableur, utilisez mr.calculer("P", "U*I", "W").
  • Script lié. Cochez lié pour suivre les changements des entrées. Placez les valeurs réglables dans les paramètres du document. Une exécution liée doit pouvoir être répétée avec les mêmes données, par exemple pour recalculer une puissance à partir des colonnes brutes.

À la réouverture du .phy, les mesures retrouvent leurs valeurs enregistrées. Régénérer le dessin exécute tout le script qui a produit le dessin. Si ce script multiplie une colonne existante par deux à chaque exécution, il la multipliera de nouveau. Conservez la mesure initiale et donnez un nom distinct à la grandeur corrigée.

Repères de calcul avec NumPy

import numpy as np donne accès à NumPy. Une tranche telle que x[2:5] contient les éléments d’indices 2, 3 et 4. Pour une mesure manquante, utilisez np.nan. Un produit, une dérivée et un ajustement portant sur deux séries doivent associer les mêmes essais.

Opération de TPÉcriture
Préparer des abscissesnp.linspace(0, 1, 11) inclut les deux bornes. np.arange(100) / 1000 représente cent instants à 1 000 Hz.
Sélectionner des couples complets_valides = np.isfinite(x) & np.isfinite(y), puis x[_valides] et y[_valides].
Résumer une sérienp.nanmean(x), np.nanstd(x, ddof=1), np.nanmedian(x), np.histogram(x[np.isfinite(x)]).
Dériver ou intégrernp.gradient(y, x) estime dy/dx. Pour une aire trapézoïdale, np.sum((y[1:] + y[:-1]) * np.diff(x) / 2) conserve le signe donné par l’ordre des abscisses.
Fonctions et unitésnp.sin(np.radians(30)) vaut 0,5. np.log est le logarithme népérien et np.log10 le logarithme décimal. Un carré s’écrit x**2.
Ajuster ou comparernp.polyfit(x, y, 1) donne pente et ordonnée à l’origine. np.polyval évalue le polynôme et np.allclose compare des résultats à une tolérance près.
Transformée de Fourier réellenp.fft.rfft(signal), np.fft.rfftfreq(n, d=pas) et np.abs. Les fréquences sont en Hz lorsque le pas est en secondes.

Filtrer un tableau sans décaler les mesures

import pandas as pd charge le module de tableaux fourni avec MeVReg. Un DataFrame regroupe les colonnes d’une acquisition. Une Series associe une valeur à chaque étiquette de ligne. Après un tri, utilisez le même masque pour les deux grandeurs d’un couple.

import mevreg as mr

_mesures = mr.tableau(["I", "U"])
_selection = _mesures[_mesures["I"] > 0]
print(_selection[["I", "U"]])
print(_selection.attrs["unites"])

Avec le TP d’Ohm, il reste les lignes à 0,10, 0,20 et 0,30 A. Les unités associées à I et U sont A et V. L’affichage console abrège les grandes acquisitions. len(_selection) donne l’effectif complet.

Lire ou construirepd.read_csv(chemin, sep=";", decimal=","), pd.DataFrame(...), pd.Series(...). Après enregistrement de la séance, un chemin relatif se rapporte au dossier de son fichier .phy.
Inspecter et choisirdf.shape, df.columns, df.head(), df.tail(), df.iloc[0], df[["I","U"]], dropna(), sort_values("I"), reset_index(drop=True).
Calculer et résumerdescribe(), count(), mean(), std() (diviseur n − 1), var(), median(), quantile(0.25), diff(), cumsum(), corr().
Assemblerpd.concat([a, b]) empile deux acquisitions. Les unités déclarées d’une même colonne doivent être compatibles. pd.concat([a, b], axis=1) juxtapose les colonnes en alignant leurs étiquettes de lignes.
Échangerdf.to_numpy(), df.to_dict("list"), df.to_csv(chemin, sep=";", decimal=",", index=False). mr.importer(df) transfère le tableau dans la séance.

Tracer une figure avec pyplot

import matplotlib.pyplot as plt utilise le tracé intégré à MeVReg. Pour une acquisition de position, plt.plot(t, x, "o") place un point par mesure. plt.xlabel("Temps (s)") et plt.ylabel("Position (m)") explicitent les axes. Terminez avec plt.show().

ReprésentationAppels disponibles
Points, courbes et dispersionplot, scatter, errorbar(x, y, xerr=..., yerr=...), hist, bar. Donnez une demi-longueur positive ou nulle pour chaque barre.
Lire et annoterxlabel, ylabel, title, grid, legend, axvline, axhline, text, annotate, xlim, ylim.
Comparer des tracésfig, ax = plt.subplots(), ax.plot(...), ax.twinx(), plt.semilogx, plt.semilogy, plt.loglog. Un axe logarithmique demande des valeurs positives.
Conserver une figureplt.savefig("mesures.svg") demande l’export. plt.show() affiche la figure dans la séance. Les formats usuels sont PNG, SVG et PDF.

Ajuster une loi et en lire les paramètres

mr.modeliser(y, x, modele="affine", degre=3, plage=None, graphe=None, nom=None) ajuste y en fonction de x et renvoie les résultats. plage=(xmin, xmax) limite les points utilisés. graphe choisit le graphe de destination et nom le libellé du modèle.

FamilleValeurs de modele
Polynômes"constante", "lineaire" (passage à l’origine), "affine", "parabole", "polynome" avec degre.
Autres lois usuelles"puissance", "exponentielle", "exp_inverse", "charge", "decharge", "ln", "log".
Oscillations et modèle personnel"sinus", "cosinus", "sinus_amorti", "cosinus_amorti" ou une expression comme "a*x^2+b". Dans cette expression, x désigne l’abscisse.

Dessiner en coordonnées physiques

Avec import fenetre as fe, un dessin possède un repère et une unité. Pour schématiser un montage en cm, créez par exemple d = fe.Dessin("Montage", xmin=0, xmax=20, ymin=0, ymax=10, unite="cm"). Chaque coordonnée des objets est alors exprimée dans cette unité.

Comprendre une erreur

La console cite une ligne du script.
Cliquez sur le lien pour retrouver la ligne. Vérifiez l’orthographe et les majuscules du nom, puis affichez les valeurs intermédiaires avec print. Un script s’exécute sans saisie interactive par input().
Un résultat ne devient pas une colonne.
Affichez _resultat.shape et _resultat.dtype. Choisissez la colonne d’une matrice avec _resultat[:, 0]. Pour une transformée complexe, np.abs donne le module. Spécifiez l’unité en publiant avec mr.creer.
La sélection de lignes ou les barres d’erreur sont refusées.
Comparez les étiquettes du masque à celles du tableau. Pour les barres d’erreur, vérifiez l’effectif et les unités de chaque série. Les demi-longueurs doivent être positives ou nulles.
Une méthode utilisée dans un autre environnement est absente.
NumPy est fourni avec l’interpréteur. Les modules de tableaux et de tracé intégrés couvrent les opérations décrites ci-dessus. Pour poursuivre avec d’autres bibliothèques, vous pouvez exporter la séance avec Fichier › Exporter vers Python (Capytale)….
Un script reçu demande à s’exécuter à l’ouverture.
Vous pouvez choisir Ne pas lancer et lire son contenu. Les accès aux fichiers s’effectuent avec les droits de votre compte. Consulter le dépannage de la séance.
