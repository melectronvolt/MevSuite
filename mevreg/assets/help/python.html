1. Les scripts

MeVReg contient son propre Python : rien à installer. Bouton Python (ou menu Python › Nouveau script), puis Exécuter (F5 ou Ctrl+Entrée) ; Arrêter interrompt une boucle trop longue. La console affiche les print et les erreurs, avec un lien vers la ligne fautive. Le menu Python › Exemples donne un exemple court pour chaque usage.

numpy, matplotlib et pandas sont des versions simplifiées, écrites pour MeVReg : elles contiennent les fonctions de cette page, qui s'utilisent comme les vraies. Un script qui s'en tient à ces fonctions donne le même résultat dans Capytale ou dans un Python installé.

import numpy as np
import matplotlib.pyplot as plt
import pandas as pd
import mevreg as mr

Un script lié (case lié) est relancé dès qu'une grandeur ou un paramètre qu'il utilise change.

2. Grandeurs et paramètres

  • Chaque grandeur du document est un tableau numpy à son nom : t, u_C, v_x… Les calculs portent sur toutes les valeurs à la fois : Ec = 0.5 * m * v**2.
  • Chaque paramètre du document est un nombre à son nom.
  • À la fin du script, chaque liste ou tableau numpy nouveau devient une grandeur du document, sans unité (nom de la variable). Une grandeur du document changée dans le script reste inchangée dans le document : la console le signale. Pour la changer : grandeur(nom, valeurs) ou mr.modifier.
  • grandeur(nom, valeurs, unite="") crée ou remplace une grandeur, avec son unité (comme mr.creer).
import numpy as np
v = np.gradient(x, t)          # nouvelle grandeur v, sans unité
grandeur("a", np.gradient(v, t), "m/s²")
print("vitesse maximale :", round(v.max(), 2), "m/s")

Pas de input() : un script ne pose pas de question. Pour changer une valeur, utilisez un paramètre (curseur) et un script lié.

6. mevreg : grandeurs

import mevreg as mr. Les lectures (valeurs, unités) se font tout de suite ; les changements du document et des graphes sont faits à la fin du script, dans l'ordre où ils ont été demandés, puis ceux des fenêtres et des fichiers (ouvrir, enregistrer, exporter).

FonctionEffet
mr.grandeurs()liste des noms des grandeurs du document
mr.valeurs(nom)valeurs de la grandeur (tableau numpy)
mr.unite(nom)unité de la grandeur ("m/s"…), vide s'il n'y en a pas
mr.parametres()paramètres du document : {nom: valeur}
mr.creer(nom, valeurs, unite="")crée la grandeur, ou remplace ses valeurs
mr.calculer(nom, formule, unite="")grandeur calculée par une formule du tableur ("0.5*m*v^2"), recalculée quand les mesures changent
mr.modifier(nom, valeurs=None, unite=None, nouveau_nom=None)change les valeurs, l'unité ou le nom
mr.renommer(nom, nouveau_nom)renomme (les formules suivent)
mr.supprimer(nom)supprime la grandeur
mr.incertitude(nom, valeur)incertitude-type : un nombre (0.02) ou une formule ("0.02*U + 0.01")
mr.parametre(nom, valeur, unite="")crée ou change un paramètre du document
 
import numpy as np
import mevreg as mr

mr.creer("v", np.gradient(mr.valeurs("x"), mr.valeurs("t")), "m/s")
mr.calculer("Ec", "0.5*m*v^2", "J")
mr.incertitude("x", 0.005)

9. mevreg : modélisation

mr.modeliser(y, x, modele="affine", degre=3, plage=None, graphe=None, nom=None) ajuste un modèle à y(x) et renvoie un résultat. Le modèle est aussi tracé sur le graphe donné, ou sur un graphe qui montre déjà y(x).

  • modele : "constante", "lineaire", "affine", "parabole", "polynome" (de degré degre), "puissance", "exponentielle", "exp_inverse", "charge", "decharge", "ln", "log", "sinus", "cosinus", "sinus_amorti", "cosinus_amorti", ou une expression : "a*x^2 + b" (x désigne l'abscisse, quel que soit son nom) ;
  • plage : (xmin, xmax), les points utilisés ;
  • nom : le nom du modèle dans la légende.

Le résultat r donne r.a ou r["a"] (valeur d'un paramètre), r.incertitudes["a"], r.parametres, r.r2, r.equation ; print(r) affiche le tout.

import mevreg as mr

r = mr.modeliser("v", "t", "affine", graphe="Vitesse")
print(r)
print("g =", round(-r.a, 2), "±", round(r.incertitudes["a"], 2), "m/s²")

11. Le module fenetre

Une fenêtre de dessin, en unités physiques : un montage, une figure de diffraction, une carte d'intensité.

import fenetre as fe

d = fe.Dessin("Montage", xmin=-1, xmax=1, ymin=-0.5, ymax=0.5, unite="m")
d.fleche(-0.8, 0, 0.8, 0, couleur="rouge")
d.texte(0, 0.1, "faisceau laser")
d.montrer()
MéthodeEffet
fe.Dessin(nom="Dessin", xmin=-1, xmax=1, ymin=-1, ymax=1, unite="", fond="blanc")nouveau dessin
d.ligne(x1, y1, x2, y2, couleur="noir", epaisseur=1.5, style="-")segment (style : "-", "--", ":", "-.")
d.fleche(x1, y1, x2, y2, couleur="noir", epaisseur=1.5)flèche
d.cercle(x, y, r, couleur="noir", epaisseur=1.5, rempli=None)cercle, rempli de la couleur donnée
d.rectangle(x, y, largeur, hauteur, couleur="noir", epaisseur=1.5, rempli=None)rectangle
d.point(x, y, couleur="noir", taille=5)point
d.texte(x, y, texte, couleur="noir", taille=12)texte
d.bandes(profil, palette="gris", longueur_onde=None, normaliser=True)figure d'une fente : bandes verticales d'intensité profil (tableau sur toute la largeur)
d.radial(profil, rmax=None, palette="gris", longueur_onde=None, normaliser=True)figure d'un trou circulaire : anneaux d'intensité profil
d.carte(expression, palette="gris", longueur_onde=None, normaliser=True, nx=500, ny=None, **parametres)intensité à deux dimensions : expression en x et y, avec ses paramètres (a=…)
d.effacer(), d.montrer()tout effacer ; afficher (ou mettre à jour) la fenêtre
fe.couleur_longueur_onde(lambda_m)couleur d'une lumière de longueur d'onde donnée, en mètres (633e-9)

Palettes : "gris", "laser" (couleur réelle de longueur_onde, en mètres : longueur_onde=633e-9), "chaud", "viridis", "bleu-rouge". Couleurs : noms français ("rouge", "bleu"…) ou "#rrggbb".
