MeVReg — Notice d'utilisation

Traitement des données des TP de physique-chimie · version {{version}}

1. À quoi sert MeVReg ?

MeVReg sert à exploiter les mesures d'un TP :

  • les saisir dans un tableur, ou les importer d'un fichier ;
  • calculer d'autres grandeurs avec des formules (vitesse, énergie…) ;
  • les tracer dans des graphes, avec leurs incertitudes ;
  • modéliser une courbe (droite, parabole, exponentielle…) et lire les paramètres du modèle, avec leur incertitude ;
  • enregistrer le travail, et faire un compte rendu en PDF.

Chaque colonne du tableur est une grandeur : un nom (t, U, v_x…), une unité et une liste de valeurs. Les interprétations restent votre travail.

2. La fenêtre

  1. 1Les menus : Fichier (ouvrir, enregistrer, importer, exporter), Édition (annuler, rétablir), Données, Graphes, Analyse, Python, Fenêtres et Aide.
  2. 2Les fenêtres de travail : Grandeurs, Tableur (un nouveau tableur), Graphe (un nouveau graphe) et Python (un nouveau script).
  3. 3Thème et langue : le soleil (thème clair) ou la lune (thème sombre) ; un clic passe à l'autre thème. Le drapeau rappelle que MeVReg n'existe pour l'instant qu'en français.
  4. 4La fenêtre Grandeurs : toutes les grandeurs du document, avec leur unité et leur nombre de valeurs. Le bouton ⋯ d'une grandeur ouvre son menu. L'onglet Calculs contient les formules.
  5. 5Le tableur et ses boutons : nouvelle grandeur mesurée ou calculée, remplissage, lignes, import et export.
  6. 6La barre de titre de chaque fenêtre : le bouton Détacher (une flèche qui sort d'un carré) la met à part, ✕ la ferme.
  7. 7Les outils du graphe : réticule, zoom, déplacement, points, plage, échelle automatique, Modéliser, export et Réglages.
  8. 8Le graphe, ici avec un modèle (courbe rouge).
  9. 9Barre d'état : à gauche, ce qui vient de se passer (en vert, une réussite ; en orange, un point à vérifier ; en rouge, une erreur) ; à droite, le fichier, le titre du TP et le nombre de grandeurs.

Les bulles d'aide. Laissez la souris un instant sur un bouton : une bulle dit ce qu'il fait. Les textes gris des fenêtres disent quoi faire.

3. Commencer

  • Nouveau tableur : un tableur vide, pour saisir vos mesures.
  • Ouvrir… (ou Ctrl+O) : un document MeVReg (.phy), donné par votre professeur ou enregistré lors d'une séance, ou un fichier de mesures .csv (partie 5).
  • Vous pouvez aussi glisser le fichier sur la fenêtre.

Un document .phy contient tout : les grandeurs, les formules, les tableurs, les graphes, les modèles, les scripts et la place des fenêtres.

4. Saisir des mesures

  1. Créez les grandeurs. + Mesure du tableur (ou la colonne +, à droite) : donnez le nom et l'unité, par exemple t et s.
  2. Tapez les valeurs : cliquez dans une case, tapez le nombre ; Entrée valide et descend, Tab passe à droite. La virgule et le point sont acceptés : 1,5 ou 1.5. Pour 2,5 × 10⁻³, tapez 2,5e-3.
  3. Vérifiez : ce qui n'est pas un nombre est refusé, et la barre d'état le signale en rouge.

Gagner du temps

  • Copier-coller depuis un autre tableur (LibreOffice, Excel…) : Ctrl+C puis Ctrl+V. Avec une ligne d'en-tête comme t (s), les grandeurs sont créées avec leur nom et leur unité.
  • Remplir… : une suite de valeurs dans la colonne choisie, par exemple de 0 à 10 par pas de 0,5.
  • Insérer une ligne, Supprimer les lignes : au-dessus du curseur, ou les lignes sélectionnées.
  • Clic droit sur un en-tête : nom, unité, incertitude, tri, statistiques, tracé en fonction de la première colonne. Double-clic : nom, unité et formule.
  • Largeur des colonnes : glissez le bord d'un en-tête ; double-clic sur le bord pour revenir à la largeur commune.

Une grandeur, plusieurs fenêtres. Une même grandeur peut figurer dans plusieurs tableurs et plusieurs graphes : changer une valeur la change partout. Pour l'ajouter à un tableur : bouton Grandeur ▾ du tableur, ou glissez-la depuis la fenêtre Grandeurs. Retirer du tableur (clic droit sur l'en-tête) ne la supprime pas.

5. Importer un fichier CSV

Les interfaces d'acquisition, les tableurs et les téléphones (applications de mesure) exportent leurs mesures en CSV : un fichier texte, une ligne par mesure. Menu Fichier › Importer un fichier CSV…, bouton Importer de la fenêtre Grandeurs, ou glissez le fichier sur la fenêtre.

MeVReg montre ce qu'il va importer avant de le faire :

  • le séparateur des valeurs (point-virgule, virgule, tabulation…) et le séparateur décimal (virgule ou point), devinés mais modifiables ;
  • la ligne des noms, celle des unités s'il y en a une, et la première ligne de valeurs ; l'option d'ignorer les lignes vides ;
  • l'aperçu : une colonne par grandeur, à cocher ou non, avec son nom et son unité (modifiables) ;
  • un résumé qui signale les problèmes : case illisible, nombre écrit avec l'autre séparateur décimal, ligne trop courte…

Vérifiez l'aperçu, puis Importer.

6. Calculer une grandeur

Une grandeur calculée est donnée par une formule ; elle est recalculée dès qu'une mesure change. Ses colonnes sont vertes, marquées ƒ.

  1. ƒ Calculée (tableur ou fenêtre Grandeurs), ou l'onglet Calculs.
  2. Écrivez nom = formule, par exemple Ec = 0.5*m*v^2, puis Entrée. Dans les formules, le séparateur décimal est le point.
ÉcritureSens
+ - * /, ^opérations, puissance (v^2)
sqrt(x), exp(x), ln(x), log(x)racine carrée, exponentielle, logarithmes népérien et décimal
sin(x), cos(x), tan(x), rad(x), deg(x)trigonométrie (en radians), conversions des angles
deriv(y, x)dérivée de y par rapport à x : v = deriv(x, t)
integ(y, x)primitive de y, nulle au premier point
mean(x), std(x), min(x), max(x), sum(x)moyenne, écart-type, minimum, maximum, somme

La liste complète est dans l'onglet Calculs (Fonctions disponibles).

Un paramètre est une constante (masse, g, k…) utilisable dans les formules : menu Données › Nouveau paramètre… Un curseur change sa valeur, et tout est recalculé aussitôt.

Renommer une grandeur met à jour toutes les formules qui l'utilisent.

7. Incertitudes

L'incertitude-type d'une grandeur est une autre grandeur, placée à sa droite : u_z pour z.

  • Bouton ⋯ de la grandeur › Incertitude › Nouvelle incertitude… (ou clic droit sur l'en-tête › Incertitude…) : une valeur (0.01) ou une formule (0.02*U + 0.01 pour « 2 % + 1 digit »).
  • Sur les graphes, les points ont alors leurs barres d'incertitude ; les réglages de la courbe choisissent barres verticales, barres en x et en y, ou rectangles, et permettent une incertitude différente de chaque côté.
  • Le réticule accroché à un point donne sa valeur avec son incertitude, arrondie à la même décimale : U = (5,04 ± 0,07) V.

8. Tracer un graphe

  1. Graphe, en haut, crée un graphe vide.
  2. Glissez des colonnes du tableur (ou des grandeurs de la fenêtre Grandeurs) sur le graphe : la première donne les abscisses, les suivantes les ordonnées. Plusieurs colonnes sélectionnées se glissent ensemble.

Autre façon : menu Graphes › Nouveau graphe y(x).

Lire et zoomer

  • Réticule (outil par défaut) : il donne les coordonnées sous la souris, et s'accroche au point de mesure le plus proche.
  • Molette : zoom autour de la souris (Maj : abscisses seules, Alt : ordonnées seules). Outil zoom : tracez un rectangle.
  • Se déplacer : glisser avec le réticule ou l'outil main ; bouton du milieu.
  • Double-clic dans le graphe : échelle automatique.

Régler

Réglages ouvre, à droite du graphe, les onglets Courbes, Axes, Titre et légende, Modèles et Annotations ; le ✕ les ferme. Double-cliquer sur un axe, le titre ou la légende ouvre le bon onglet. Plusieurs graphes dans une fenêtre : bouton grille de la barre du graphe.

Droites et textes

Clic droit sur le graphe › Ajouter ici : droite verticale, horizontale, oblique, ou texte. Cliquez une droite ou un texte pour le sélectionner, puis glissez-le ; les poignées d'une droite oblique changent sa pente. Le cadenas (clic droit, ou onglet Annotations) évite de les déplacer par erreur ; Suppr supprime l'annotation sélectionnée.

9. Modéliser

Modéliser, c'est chercher la fonction qui passe au plus près des points, et ses paramètres.

  1. Bouton Modéliser du graphe : la fenêtre Modélisation s'ouvre à part, à côté de la fenêtre principale.
  2. Choisissez la courbe, puis un modèle (+ Nouveau modèle et une vignette) : affine, linéaire, parabole, exponentielle, charge ou décharge d'un condensateur, sinus, sinus amorti, puissance… Le modèle est ajusté et tracé aussitôt.
  3. Lisez les paramètres et leur incertitude-type, l'équation et R² (plus il est proche de 1, mieux le modèle décrit les points).
  • Points : tous, ou une plage : deux barres verticales apparaissent sur le graphe ; glissez-les pour choisir les points utilisés.
  • Courbe tracée : sur tout le graphe (elle se prolonge avant et après les points, et suit le zoom), sur les points, ou de … à … (barres en pointillés, à glisser sur le graphe).
  • Légende : le nom du modèle sur le graphe. Fixé : impose la valeur d'un paramètre.
  • Créer la grandeur modèle ajoute les valeurs du modèle au document ; Copier les résultats les copie pour un compte rendu.
  • Modèle à écrire soi-même (Utilisateur) : par exemple a*t^2 + b, avec la variable de l'axe des abscisses.

10. Autres analyses

Menu Analyse :

  • Statistiques d'une série de mesures répétées : moyenne, écart-type, incertitude-type (type A) et histogramme.
  • Dérivée…, Dérivée seconde…, Intégrale… : une nouvelle grandeur calculée.
  • Spectre (analyse de Fourier)… : les fréquences présentes dans un signal.
  • Méthode des tangentes… et Méthode de la dérivée… : repérer l'équivalence d'un dosage. Les tangentes se déplacent à la souris ; clic droit pour les verrouiller ou les supprimer.

11. Enregistrer, exporter, imprimer

  • Enregistrer : Ctrl+S, un document .phy. Ctrl+Z annule la dernière modification, Ctrl+Y la rétablit.
  • Compte rendu : Fichier › Compte rendu du TP en PDF… (tableurs, calculs, graphes, modèles, scripts), ou Imprimer le compte rendu… Le titre, les noms et la classe se donnent dans Fichier › Informations du TP…
  • Image d'un graphe : bouton d'export du graphe (ou clic droit) : copier l'image, PNG, SVG, PDF, imprimer.
  • CSV : Fichier › Exporter toutes les grandeurs en CSV…, ou CSV, PDF ▾ du tableur. On choisit le séparateur, la virgule ou le point décimal, l'en-tête et l'encodage, avec un aperçu.

12. Ranger les fenêtres

  • Déplacer : glissez la barre de titre d'une fenêtre ; des repères montrent où elle se placera (à côté, dessous, ou en onglet avec une autre).
  • Détacher : le bouton Détacher de la barre de titre (une flèche qui sort d'un carré) met la fenêtre à part, avec son propre cadre : pratique avec deux écrans. Son bouton Rattacher la remet dans la fenêtre principale.
  • Fermer : ✕. MeVReg demande s'il faut cacher la fenêtre (elle reste dans le document : menu Fenêtres pour la rouvrir) ou la fermer (le tableur, le graphe ou le script est supprimé ; Ctrl+Z le rend).
  • Menu Fenêtres : toutes les fenêtres, ouvertes ou cachées ; le ✕ d'une ligne ferme la fenêtre. Disposition par défaut range tout.

14. En cas de problème

Une formule est marquée d'un triangle rouge.
Elle contient une erreur : laissez la souris sur le triangle, la bulle dit laquelle (nom inconnu, parenthèse manquante…). Dans les formules, le séparateur décimal est le point : 0.5, pas 0,5.
Le graphe est vide, ou les points sont hors de vue.
Double-cliquez dans le graphe : l'échelle s'ajuste aux données. S'il n'y a aucune courbe, glissez-y des colonnes du tableur.
Le modèle ne passe pas par les points.
Vérifiez la courbe choisie et la plage de points. Essayez un autre modèle, ou fixez la valeur d'un paramètre.
L'import CSV donne des valeurs fausses.
Vérifiez dans l'aperçu le séparateur décimal (virgule ou point) et la première ligne de valeurs.
Une fenêtre a disparu.
Elle est cachée : menu Fenêtres. Disposition par défaut range toutes les fenêtres.
Les textes sont devenus énormes (ou minuscules).
Ctrl+0 rétablit la taille normale.
Une modification est une erreur.
Ctrl+Z l'annule, même la fermeture d'un tableur ou d'un graphe.

15. Python dans MeVReg

MeVReg contient Python : aucune installation n'est nécessaire. Python, en haut, ouvre un nouveau script ; Exécuter (F5) le lance, la console affiche les print et les erreurs, avec le numéro de la ligne.

  • Les grandeurs du document sont des tableaux numpy, à leur nom (t, u_C…) ; les paramètres sont des nombres.
  • Une liste ou un tableau créé dans le script devient une grandeur (sans unité) ; mr.creer("P", P, "W") lui donne une unité.
  • Les figures matplotlib (plt.plot, plt.show…) deviennent des graphes de MeVReg, modifiables à la souris.
  • Le module mevreg (import mevreg as mr) pilote tout le logiciel : grandeurs, tableurs, graphes, modélisation, fenêtres, fichiers.
  • Script lié (case lié) : relancé dès qu'une grandeur ou un paramètre qu'il utilise change.
  • Menu Python › Exemples : un exemple court pour chaque usage (grandeurs, graphes, modélisation, fenêtres et fichiers, divers), à copier et adapter.

Les fonctions disponibles de numpy, matplotlib et pandas, et toutes celles du module mevreg avec leurs paramètres, sont dans la référence Python.

Capytale. Fichier › Exporter vers Python (Capytale)… écrit un script numpy + matplotlib qui refait les données, les calculs et les graphes. Un script qui n'utilise que numpy, matplotlib et pandas donne le même résultat dans Capytale.

16. Préparer un TP

  • Préparez les grandeurs (noms, unités, incertitudes), les formules, les tableurs et les graphes, puis Fichier › Enregistrer : le .phy, distribué aux élèves, s'ouvre avec les mêmes fenêtres, à la même place.
  • Fichier › Informations du TP… : titre, noms des élèves, classe et notes, repris en tête du compte rendu PDF.
  • Un script lié peut faire un calcul que les élèves ne voient pas (fenêtre cachée), ou tracer une figure qui suit leurs mesures.
  • Le module fenetre dessine en unités physiques (montages, figures de diffraction et d'interférences) : voir la référence Python.

17. Installer et configurer

Installation

  • Windows, sans installation : MeVReg tient dans un dossier (archive .zip), à copier sur le poste, le réseau du lycée ou une clé USB ; lancer mevreg.exe. Python y est compris. Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur », car MeVReg n'est pas signé numériquement : « Informations complémentaires », puis « Exécuter quand même ».
  • Windows, installateur : MeVReg-version-windows-x64-setup.exe installe MeVReg pour tous les utilisateurs dans Program Files\MeVSuite, avec un raccourci dans le menu Démarrer ; il se désinstalle par les Paramètres de Windows. Déploiement sur un parc (WAPT, GPO) : options /VERYSILENT /SUPPRESSMSGBOXES /NORESTART.
  • Linux : paquet .deb (Ubuntu, Debian), .rpm (Fedora), ou .AppImage, qui se lance sans installation (le rendre exécutable).
  • Vidéoprojecteur : Ctrl++ agrandit les textes et les graphes ; Ctrl+0 revient à la taille normale.

Préférences et réglages

Édition › Préférences… : graphes sur fond sombre avec le thème sombre, confirmation avant de fermer une fenêtre, chiffres significatifs des tableurs.

Au premier lancement, MeVReg prend le thème clair ou sombre du système. Il retient d'une séance à l'autre le thème, les préférences, l'agrandissement des textes, les derniers fichiers et la taille de la fenêtre, dans un petit fichier texte mevreg.ini, propre à chaque utilisateur ; le supprimer rétablit les valeurs par défaut. Son chemin est affiché dans Aide › À propos de MeVReg…

SystèmeEmplacement
Windows%APPDATA%\MeVSuite\mevreg.ini
Linux~/.config/MeVSuite/mevreg.ini

Les quatre logiciels de la suite (MeVPix, MeVCine, MeVReg, MeVSono) rangent leurs réglages dans ce même dossier MeVSuite.
