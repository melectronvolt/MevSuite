Settings

For teachers: the configuration, the folders, the environment variables

What MeVCine remembers

Languagethe flag, at the top right (French or English); without a choice, the system language
Themethe sun or moon, at the top right; without a choice, the desktop theme
Modethe last one chosen in the Mode menu; on first launch, the one chosen on the welcome page (the --simple and --expert options enforce it)
Unit of the referencethe last one chosen (mm, cm or m)
Windowits size, and whether it was maximised
Enlargementthe size of the interface texts, chosen with Ctrl++ and Ctrl+− (from 50 to 300%)
Video folderthe last one used, offered by Open a video…

On screen, numbers follow the language (decimal comma in French, point in English). The exports (Python, CSV) always use a decimal point, and project files do not depend on the language.

The configuration file

These settings are in mevcine.ini, for each user, in the folder shared by the programs of the suite (MeVPix, MeVCine, MeVReg, MeVSono):

Windows%APPDATA%\MeVSuite\ (usually C:\Users\name\AppData\Roaming\MeVSuite\)
Linux~/.config/MeVSuite/

The same folder contains mevcine-secours.mevcine, the automatic backup of the work in progress, and mevcine.log, the error log: each internal error or crash is added to it, dated, with its cause (and, for a crash, the call stack). If the configuration file is unreadable, MeVCine says so and starts from a fresh configuration; deleting it resets all the settings. The files of an older version (mevcine folder) are moved there on first launch, and projects of the previous version, CineMev (.cinemev), open in MeVCine.

The settings of the computer are written there in plain text: langue = fr (or en), theme = light (or dark; auto, or nothing, follows the desktop), mode = simplifie (or expert), agrandissement = 1.2, taille_fenetre = (1200,700), fenetre_maximisee = False. They never go into project files.

Environment variables

MEVCINE_CONFanother configuration folder (a folder shared by a room, a folder on the USB stick)
MEVCINE_DATAanother data folder (the user guide), instead of the data folder next to the program

Folders

  • ffmpeg/, next to the program: the shipped ffmpeg. If it is missing, MeVCine uses the ffmpeg installed on the computer (in the PATH), which cannot always decode HEVC.
  • data/help: this guide. It opens in the web browser, from a copy made again each time in the system's temporary folder (mevcine-help).
  • Open dialogs offer the last video folder, otherwise the user's Videos (or Downloads) folder; save dialogs, the Documents folder.

The window

The window can be resized freely (at least 900 × 600): the frame takes the available room, the control columns scroll if the window is short, and the points stay right, since they are kept in video pixels. In simple mode, the width of the table of measurements is set by dragging its edge.
