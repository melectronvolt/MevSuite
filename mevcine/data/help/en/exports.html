Understand the columns

The first measured frame sets t = 0. Times are in seconds. Coordinates use the chosen axes and are in metres after calibration or pixels beforehand. For two objects, the column order is t, x1, y1, x2, y2.

Suppose object 1 is hidden in the second frame while object 2 remains visible. At 25 frames/s, part of a calibrated CSV file might read as follows.

t (s),x1 (m),y1 (m),x2 (m),y2 (m)
0,0,0,0.30,0.12
0.04,,,0.31,0.12

The second row keeps its time and the position of object 2. The first position (0, 0) is a measurement at the origin. The hidden object's two empty fields become np.nan in Python. Both exports retain every frame between the first and last measurement, including a frame from which all marks were deleted.

Copy for Python

Copy for Python (step 5, Coordinates tab, File menu, or Ctrl+C) copies the measurements as three numpy arrays, lst_t, lst_x and lst_y. Paste the text with Ctrl+V at the start of your program or in a notebook cell, then add your calculations.

Numbers have 6 significant digits. With several objects, the lists are named lst_x1, lst_y1, lst_x2… “Measurements on the clipboard” disappears when another copy replaces the data or the measurements change.

The CSV file

Save as CSV… writes a standard file: a comma between columns, a decimal point, a header row.

To read it in Python:

import numpy as np
lst_t, lst_x, lst_y = np.genfromtxt("measurements.csv", delimiter=",", skip_header=1, unpack=True)

For two objects, assign the five columns to t, x1, y1, x2, y2. An empty field gives np.nan and its time stays in the array.

A spreadsheet set to a language that uses a decimal comma may need to be told that the file uses a decimal point: choose “English (USA)” as the language of the import.

Saving an image

In expert mode, Save in the Trajectories tab writes the drawing (trajectory, chronophotography, motion diagram) as PNG or JPEG; the one of the Grapher writes the graph as PNG: handy for a report.

Projects

Save with Ctrl+S. The .mevcine file stores the axes, scale, frame rate, positions, recorded absences and corrections. The video remains a separate file. Copy both files into the same folder when moving to another computer.

A session interrupted after the first of two objects resumes with the second. An automatic run completed in expert mode reopens on Coordinates. Older MeVCine and CinéMev projects also open. If you need to locate the video of an older project that has no fingerprint, check the recording before confirming.

Save and recover work

Ctrl+S saves the project to the location you choose. You can save between marks on the same frame. Each session also has its own automatic backup, including during automatic tracking. After an interruption, use File › Recover previous work…. If several backups appear, choose yours by video name and modification date. Check the last mark and save the project in your working folder.

If MeVCine reports a write error, choose a writable folder and use Save the project… before closing. The Cancel button in the quit dialog returns to the project.
