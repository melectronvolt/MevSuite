Dépannage

Pour les professeurs : les messages de MeVCine, et quoi faire

Les petits problèmes du TP (pointage, longueur refusée, dates, export) sont dans les questions fréquentes. Voici les problèmes techniques.

La vidéo ne s'ouvre pas

« Vidéo illisible : la vidéo est au format HEVC (H.265), que ffmpeg n'a pas su décoder »
Le ffmpeg utilisé ne connaît pas ce format. Vérifiez que le dossier ffmpeg est bien à côté du programme, ou installez un ffmpeg complet. Sinon, convertissez la vidéo en H.264 : 
ffmpeg -i video.mov -c:v libx264 -pix_fmt yuv420p -an video.mp4
(ou avec HandBrake, VLC…). Une conversion peut perdre la cadence d'un ralenti.
« le programme ffprobe est introuvable : ffmpeg doit être installé pour lire les vidéos »
Ni le dossier ffmpeg à côté du programme, ni un ffmpeg installé. Recopiez le dossier complet de MeVCine, ou installez ffmpeg (sudo apt install ffmpeg, sudo dnf install ffmpeg…).
« ce fichier n'est pas une vidéo », « ce fichier ne contient pas de vidéo »
Le fichier est autre chose (une image, un son), ou il est abîmé. Essayez de le lire avec VLC.
« impossible de déterminer le nombre d'images »
Le fichier est incomplet (transfert interrompu). Refaites le transfert, ou réencodez-le avec la commande ci-dessus.
« Image 57 illisible » dans la barre d'état
Une image de la vidéo n'a pas pu être décodée (fichier abîmé). Les autres restent utilisables.
MeVCine est lent avec une vidéo 4K
Le décodage d'une image 4K prend du temps, surtout en revenant en arrière. Réduisez la vidéo : ffmpeg -i video.mp4 -vf scale=1920:-2 -c:v libx264 petite.mp4.

La fenêtre ne s'ouvre pas

« This application failed to start because no Qt platform plugin could be initialized »
Les bibliothèques de Qt sont incomplètes. Sous Windows, le dossier platforms (avec qwindows.dll) doit être à côté de mevcine.exe : recopiez le dossier complet. Sous Linux, installez le paquet de MeVCine, ou prenez l'AppImage (voir Installer).
Rien ne se passe au double-clic (Windows)
SmartScreen a peut-être bloqué le programme : relancez-le, puis Informations complémentaires › Exécuter quand même. Vérifiez aussi que l'antivirus ne l'a pas mis en quarantaine.
Les flèches des boutons (◀ ▶ ↶ ⟳) sont des carrés
Aucune police du système ne contient ces symboles. Sous Linux, installez les polices DejaVu (fonts-dejavu ou dejavu-sans-fonts).

Les fichiers

Aucune fenêtre ne s'ouvre avec Ouvrir une vidéo… (Linux)
MeVCine utilise les dialogues du bureau, sinon ceux de Qt. En attendant, glissez la vidéo sur la fenêtre, ou lancez ./mevcine video.mp4.
« Fichier trop ancien »
Un ancien fichier .mecavideo antérieur à la version 7.3 : son format n'est pas lisible.
« Projet illisible »
Le fichier n'est pas un projet MeVCine, ou il est abîmé.
« Erreur lors de l'enregistrement »
Le dossier n'est pas accessible en écriture (clé protégée, dossier réseau plein, droits). Choisissez un autre dossier, par exemple Documents.

Une erreur interne, un plantage

« Erreur interne de MeVCine »
Le programme a rencontré une erreur imprévue et s'arrête. Le détail est dans mevcine-erreurs.log (dossier de configuration) : envoyez-le à suite@sciences-physiques.net, avec la vidéo si possible.
Récupérer le travail en cours
Relancez MeVCine, puis Fichier › Récupérer le travail précédent… : la sauvegarde automatique (au plus deux secondes avant l'arrêt) revient.
« Erreur de lecture de la configuration »
Le fichier mevcine.ini est abîmé : MeVCine repart d'une configuration neuve. Rien de grave.
