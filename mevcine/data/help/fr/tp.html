Un TP pas à pas

Le principe d'inertie, avec la vidéo d'un palet sur une table

La question : un palet glisse sur une table presque sans frottement. Son mouvement est-il rectiligne et uniforme ? Nous allons le mesurer avec MeVCine, puis le vérifier avec Python. Durée : une vingtaine de minutes.

1. Mesurer avec MeVCine

  1. Lancez MeVCine, choisissez Mode simplifié, puis 📂 Ouvrir une vidéo… et choisissez la vidéo donnée par votre professeur (ici Principe_inertie.avi : un palet sur une table, avec une règle jaune de 85 cm).
  2. Origine : cliquez sur l'extrémité gauche de la règle jaune. Suivant ▶
  3. Axes : choisissez « x vers la droite, y vers le haut ». Suivant ▶
  4. Échelle : Sélectionner l'étalon, cliquez sur les deux bouts de la règle jaune ; tapez 85, choisissez cm, Valider. Suivant ▶
  5. Pointage : avec la glissière, allez à la première image où le palet a quitté la main (vers l'image 3). Cliquez sur le centre du palet, image après image, en regardant la loupe, jusqu'à ce qu'il sorte de l'image. Terminer le pointage ▶
  6. Tableau : vérifiez les valeurs ; refaites avec ⌖ une mesure qui paraît fausse. Suivant ▶
  7. Export : 📋 Copier pour Python.

Avant d'exporter, passez en mode expert (menu Mode), onglet Trajectoires, et cochez Montrer les vecteurs vitesse : des flèches de même longueur, dans la même direction, annoncent déjà un mouvement rectiligne uniforme. Revenez ensuite en mode simplifié : rien n'est perdu.

2. Exploiter avec Python

Collez le texte copié (Ctrl+V) au début d'un programme, puis ajoutez :

import matplotlib.pyplot as plt

# vitesse entre deux images successives, au milieu de chaque intervalle
t_milieu = (lst_t[1:] + lst_t[:-1]) / 2
vx = np.diff(lst_x) / np.diff(lst_t)
vy = np.diff(lst_y) / np.diff(lst_t)
print("vx moyenne :", vx.mean(), "m/s")

# la droite qui passe au plus près des points x(t)
a, b = np.polyfit(lst_t, lst_x, 1)
print(f"x(t) ≈ {a:.3f} t + {b:.3f}")

plt.subplot(1, 2, 1)
plt.plot(lst_t, lst_x, "o", lst_t, a * lst_t + b, "-")
plt.xlabel("t (s)"); plt.ylabel("x (m)")
plt.subplot(1, 2, 2)
plt.plot(t_milieu, vx, "o", t_milieu, vy, "s")
plt.xlabel("t (s)"); plt.ylabel("vitesse (m/s)")
plt.tight_layout()
plt.show()

3. Conclure

  • Les points y(t) sont presque constants : la trajectoire est une droite parallèle à l'axe x.
  • Les points x(t) sont alignés : x varie de la même quantité à chaque intervalle de temps, la vitesse est constante. Son signe dépend du sens choisi pour l'axe x.
  • Les vitesses calculées image par image ne sont pas toutes égales : de petits écarts viennent du pointage (par exemple, un pixel d'erreur sur un déplacement de 15 pixels entre deux images, c'est près de 7 %). Plus on vise le même point du palet, plus ces écarts sont faibles.

Pour aller plus loin : déplacez l'origine, ou changez le sens de x (étapes 1 et 2), et regardez ce qui change dans le tableau. La forme du mouvement, elle, ne dépend pas du repère.
