Dépannage

Pour les professeurs : les messages de MeVCine, et quoi faire

Les petits problèmes du TP (pointage, longueur refusée, dates, export) sont dans les questions fréquentes. Voici les problèmes techniques.

La vidéo ne s'ouvre pas

La vidéo ne s’ouvre pas, ou l’examen dépasse deux minutes.
Copiez le film sur le disque du poste, vérifiez que le transfert est terminé et essayez de lire le début et la fin. Un échec à l’examen peut venir du fichier, du support ou du décodeur.
Le message cite FFprobe ou FFmpeg.
Avec la version portable, vérifiez le dossier ffmpeg livré près du programme. Avec un paquet Linux, vérifiez l’installation des deux outils sur le poste. Voir Installer sous Linux.
La vidéo HEVC (H.265) est reconnue mais ne se décode pas.
Essayez la distribution de MeVCine fournie avec FFmpeg. Si vous convertissez une copie, utilisez un autre nom et gardez la cadence d’origine dans vos notes. Un exemple pour produire une copie H.264 est ffmpeg -i video.mov -c:v libx264 -pix_fmt yuv420p -an copie.mp4. Contrôlez ensuite ses dates avant de mesurer.
La barre d’état indique « Image 57 illisible ».
Le suivi s’interrompt à cette image. Rétablissez l’accès au film, puis cliquez sur Réessayer. Les mesures précédentes restent disponibles. Quand l’image revient, vous pouvez poursuivre à la main.
L’aller-retour entre images est lent sur une vidéo 4K.
Essayez d’abord le disque local. Si vous préparez un film plus petit pour la classe, réduisez une copie avant l’étalonnage, par exemple avec ffmpeg -i video.mp4 -vf scale=1920:-2 -c:v libx264 copie.mp4 pour un film en paysage.

La fenêtre ne s'ouvre pas

« This application failed to start because no Qt platform plugin could be initialized »
Les bibliothèques de Qt sont incomplètes. Sous Windows, le dossier plugins (avec plugins\platforms\qwindows.dll) et le fichier qt.conf doivent être à côté de mevcine.exe : recopiez le dossier complet. Sous Linux, installez le paquet de MeVCine, ou prenez l'AppImage (voir Installer).
Rien ne se passe au double-clic (Windows)
SmartScreen a peut-être bloqué le programme : relancez-le, puis Informations complémentaires › Exécuter quand même. Vérifiez aussi que l'antivirus ne l'a pas mis en quarantaine.

Les fichiers

Aucune fenêtre ne s'ouvre avec Ouvrir une vidéo… (Linux)
MeVCine utilise les dialogues du bureau, sinon ceux de Qt. En attendant, glissez la vidéo sur la fenêtre, ou lancez mevcine video.mp4.
« Fichier non reconnu »
Le fichier n'a pas été écrit par MeVCine, ou son en-tête est abîmé : il ne peut pas être ouvert.
« Projet illisible »
MeVCine indique la ligne concernée si une paire x, y est incomplète ou contient du texte. Retrouvez le fichier d’origine ou une copie de secours. Le projet déjà affiché reste ouvert après ce refus.
« Vidéo introuvable »
Gardez la vidéo avec le projet pour le transporter. Si elle a été déplacée ou renommée, choisissez-la à l’ouverture du projet. MeVCine vérifie son empreinte. Pour un projet ancien sans empreinte, vérifiez vous-même la vidéo avant de confirmer.
« Erreur lors de l'enregistrement »
Le dossier n'est pas accessible en écriture (clé protégée ou pleine, dossier réseau plein, droits) ; le message en donne la cause. Un fichier qui existait déjà reste intact. Choisissez un autre dossier, par exemple Documents.
« Sauvegarde automatique impossible »
Le dossier de configuration n'est pas accessible en écriture (disque plein, droits). Le travail n'est plus protégé : enregistrez le projet (Fichier › Enregistrer le projet…) ailleurs, puis libérez de la place ou corrigez les droits (voir Réglages).

Le projet contient des modifications

Pour garder le repère, l’étalon et les points, choisissez Annuler, puis Fichier › Enregistrer le projet…. Une copie Python ou un CSV fournit les nombres pour l’analyse. Le fichier .mevcine permet de rouvrir la séance.

Une erreur interne, un plantage

« Erreur interne de MeVCine »
Le programme a rencontré une erreur imprévue, ou il a planté, et s'arrête. Le message dit où est le journal : mevcine.log, dans le dossier de configuration, avec la date, la cause et, pour un plantage, la pile d'appels. Envoyez-le à suite@sciences-physiques.net, avec la vidéo si possible.
Récupérer le travail en cours
Relancez MeVCine et ouvrez Fichier › Récupérer le travail précédent…. Si plusieurs copies sont disponibles, choisissez votre vidéo à la date de la séance. Après une fermeture imprévue, vérifiez les clics des deux dernières secondes.
« Erreur de lecture de la configuration »
Le fichier mevcine.ini est abîmé : MeVCine repart d'une configuration neuve. Rien de grave.
