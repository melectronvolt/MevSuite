Installer MeVCine

Pour les professeurs : une version portable ou un installateur sous Windows, un paquet ou une AppImage sous Linux

La version portable (Windows)

MeVCine-version-windows-x64.zip contient un dossier, MeVCine-version, à copier tel quel, sans installation (clé USB, dossier partagé, disque de chaque poste). Il contient :

mevcine.exele programme, avec les bibliothèques de Qt (les fichiers *.dll, les dossiers plugins et translations, et qt.conf)
ffmpeg/les programmes ffmpeg et ffprobe, qui lisent les vidéos (HEVC des téléphones compris), avec leur licence. Ne séparez pas ces fichiers du dossier.
data/helpcette notice
licences/les licences des bibliothèques livrées, et la liste de leurs versions
COPYING.txt, NOTICE.txtla licence de MeVCine
LISEZMOI.txtle premier lancement, en quelques lignes

L'installateur (Windows)

MeVCine-version-windows-x64-setup.exe installe le même dossier pour tous les utilisateurs dans Program Files\MeVSuite\MeVCine, avec un raccourci dans le menu Démarrer (dossier MeVSuite) et, si on le demande, sur le bureau. Les projets .mevcine s'ouvrent alors d'un double clic. Il se désinstalle par les Paramètres de Windows. Déploiement sur un parc (WAPT, GPO), sans fenêtre ni question :

MeVCine-version-windows-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

Désinstallation silencieuse :

"C:\Program Files\MeVSuite\MeVCine\unins000.exe" /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

L'identifiant de l'installateur ne change pas d'une version à l'autre : une nouvelle version remplace l'ancienne.

Sous Windows

Double-cliquez sur mevcine.exe (ou sur le raccourci du menu Démarrer). Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur », car le programme n'est pas signé : Informations complémentaires, puis Exécuter quand même.

L'affichage ne demande aucune accélération graphique : MeVCine fonctionne aussi dans une machine virtuelle ou un bureau à distance. Si la fenêtre ne s'ouvre pas, voyez le dépannage.

Sous Linux

  • Ubuntu 26.04 : sudo apt install ./mevcine_version_amd64.deb.
  • Fedora 45 : sudo dnf install ./mevcine-version-1.fc45.x86_64.rpm. Le ffmpeg de Fedora (ffmpeg-free) ne décode pas tous les formats des téléphones (HEVC notamment) : installez celui de RPM Fusion (dépôt RPM Fusion activé, puis sudo dnf swap ffmpeg-free ffmpeg --allowerasing).
  • AppImage, sans installation, pour les distributions récentes (Ubuntu 24.04, Debian 13, Fedora 40 ou plus récentes) : MeVCine-version-x86_64.AppImage, un seul fichier, ffmpeg compris, à rendre exécutable (clic droit › Propriétés, ou chmod +x) puis à lancer.

Le paquet installe MeVCine dans le menu des applications, avec ffmpeg ; les projets .mevcine s'ouvrent d'un double clic, et les vidéos par Ouvrir avec › MeVCine. Il faut un bureau graphique (Wayland ou X11). Les dialogues de fichiers sont ceux du bureau (GNOME, KDE…), et le thème sombre du bureau est suivi tant que l'élève n'a pas choisi le sien.

Au premier lancement

  • MeVCine s'ouvre en mode simplifié, et propose d'ouvrir une vidéo. Ensuite, il reprend le mode de la dernière fois.
  • Il prend la langue du système si c'est le français, sinon l'anglais ; le thème clair ou sombre du bureau. Le drapeau et le soleil (ou la lune), en haut à droite de la fenêtre, les changent ; le choix est retenu.
  • La fenêtre s'ouvre à sa taille normale (1200 × 700, réduite si l'écran est plus petit), jamais agrandie d'office ; elle garde ensuite la taille que l'utilisateur lui a donnée (et reste agrandie si on l'a agrandie).
  • MeVCine ne rouvre jamais la dernière vidéo : il retient seulement le dernier dossier de vidéos.

La ligne de commande

mevcine                          le mode de la dernière fois
mevcine --simple chute.mp4       mode simplifié (ou -s), avec une vidéo
mevcine --expert projet.mevcine  mode expert (ou -e), avec un projet
mevcine -d 2 …                   messages de débogage (1 à 3)
mevcine --help                   ces options

Sans option, MeVCine prend le mode de la dernière fois (au premier lancement, il le fait choisir) ; un raccourci vers mevcine.exe --simple ouvre toujours le mode simplifié. Un projet (.mevcine, .cinemev, ancien .mecavideo) se donne aussi sur la ligne de commande, ou se glisse sur la fenêtre. Voir Déployer MeVCine dans une salle.
