Installer MeVCine

Pour les professeurs : un dossier à copier ou un installateur sous Windows, un paquet ou une AppImage sous Linux

Le dossier de MeVCine (Windows)

Sous Windows, MeVCine est livré sous la forme d'un dossier (archive .zip), sans installation, à copier tel quel (clé USB, dossier partagé, disque de chaque poste). Il contient :

mevcine.exele programme, avec les bibliothèques de Qt (les fichiers *.dll et le dossier platforms)
ffmpeg/les programmes ffmpeg et ffprobe, qui lisent les vidéos (HEVC des téléphones compris). Ne séparez pas ces fichiers du dossier.
data/cette notice (help)
COPYING.txt, NOTICE.txtla licence

Installateur (Windows)

MeVCine-version-windows-x64-setup.exe installe le même dossier pour tous les utilisateurs dans Program Files\MeVSuite\MeVCine, avec un raccourci dans le menu Démarrer ; il se désinstalle par les Paramètres de Windows. Déploiement sur un parc (WAPT, GPO), sans fenêtre ni question :

MeVCine-version-windows-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

Sous Windows

Double-cliquez sur mevcine.exe. Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur », car le programme n'est pas signé : Informations complémentaires, puis Exécuter quand même.

L'affichage ne demande aucune accélération graphique : MeVCine fonctionne aussi dans une machine virtuelle ou un bureau à distance. Si la fenêtre ne s'ouvre pas, voyez le dépannage.

Sous Linux

  • Paquet : .deb pour Ubuntu et Debian, .rpm pour Fedora. Il installe MeVCine dans le menu des applications, avec ffmpeg (sous Fedora, le ffmpeg de RPM Fusion décode le H.264 et le HEVC des téléphones ; celui de Fedora, ffmpeg-free, ne les décode pas tous).
  • AppImage, sans installation : un seul fichier, ffmpeg compris, à rendre exécutable (clic droit › Propriétés, ou chmod +x) puis à lancer.

Il faut un bureau graphique (Wayland ou X11). Les dialogues de fichiers sont ceux du bureau (GNOME, KDE…), et le thème sombre du bureau est suivi tant que l'élève n'a pas choisi le sien.

Au premier lancement

  • MeVCine prend la langue du système si c'est le français, sinon l'anglais ; le thème clair ou sombre du bureau. Le drapeau et le soleil (ou la lune), en haut à droite de la fenêtre, les changent ; le choix est retenu.
  • La fenêtre s'ouvre à sa taille normale (1200 × 700, réduite si l'écran est plus petit), jamais agrandie d'office ; elle garde ensuite la taille que l'utilisateur lui a donnée (et reste agrandie si on l'a agrandie).
  • MeVCine ne rouvre jamais la dernière vidéo : il retient seulement le dernier dossier de vidéos.

La ligne de commande

mevcine                        écran d'accueil : choix du mode
mevcine --simple chute.mp4     mode simplifié, avec une vidéo
mevcine --expert projet.mevcine
mevcine -d 2 ...               messages de débogage (1 à 3) dans le terminal

Un raccourci vers mevcine.exe --simple ouvre directement le mode simplifié. Un projet (.mevcine, .cinemev, ancien .mecavideo) se donne aussi sur la ligne de commande, ou se glisse sur la fenêtre. Voir Déployer MeVCine dans une salle.
