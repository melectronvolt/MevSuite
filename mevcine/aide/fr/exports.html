Comprendre les colonnes

La première image de mesure fixe t = 0. Les dates sont en secondes. Les coordonnées sont exprimées dans le repère choisi, en mètres après étalonnage ou en pixels avant. Avec deux mobiles, l’ordre est t, x1, y1, x2, y2.

Supposons que le mobile 1 soit caché sur la deuxième image et que le mobile 2 reste visible. À 25 images/s, un extrait de CSV étalonné peut se lire ainsi.

t (s),x1 (m),y1 (m),x2 (m),y2 (m)
0,0,0,0.30,0.12
0.04,,,0.31,0.12

La deuxième ligne conserve sa date et la position du mobile 2. La première position (0, 0) correspond à une mesure à l’origine. Les deux champs vides du mobile caché deviennent np.nan en Python. Le CSV et les tableaux Python gardent chaque image entre le début et la fin de la série, y compris une image dont tous les points ont été effacés.

Copier pour Python

Copier pour Python (étape 5, onglet Coordonnées, menu Fichier, ou Ctrl+C) copie les mesures dans trois tableaux numpy, lst_t, lst_x et lst_y. Collez le texte avec Ctrl+V au début de votre programme ou dans une cellule de notebook, puis écrivez vos calculs à la suite.

Les nombres ont 6 chiffres significatifs. Avec plusieurs objets, les listes s'appellent lst_x1, lst_y1, lst_x2… Le message « Mesures dans le presse-papiers » disparaît si une autre copie le remplace ou si les mesures changent.

Le fichier CSV

Enregistrer en CSV… écrit un fichier standard : une virgule entre les colonnes, le point décimal, une ligne d'en-tête.

Pour le lire en Python :

import numpy as np
lst_t, lst_x, lst_y = np.genfromtxt("mesures.csv", delimiter=",", skip_header=1, unpack=True)

Pour deux objets, affectez les cinq colonnes à t, x1, y1, x2, y2. Un champ vide donne np.nan. Sa date reste dans le tableau.

  • LibreOffice Calc : à l'ouverture, cochez la virgule comme séparateur, et choisissez « Anglais (USA) » comme langue, pour que le point décimal soit compris.
  • Excel : Données › À partir d'un fichier texte/CSV, délimiteur virgule, paramètres régionaux « Anglais (États-Unis) ».

Enregistrer une image

En mode expert, Enregistrer de l'onglet Trajectoires écrit le dessin (trajectoire, chronophotographie, chronogramme) en PNG ou JPEG ; celui du Grapheur écrit le graphique en PNG : pratique pour un compte rendu.

Projets

Enregistrez avec Ctrl+S. Le fichier .mevcine conserve le repère, l’étalon, la cadence, les positions, les absences signalées et les corrections. La vidéo reste dans son propre fichier. Copiez les deux fichiers dans le même dossier pour changer de poste.

Une séance interrompue après le premier de deux objets se rouvre sur le second. Un pointage expert mené jusqu’à la dernière image se rouvre sur les coordonnées. Les anciens projets MeVCine ou CinéMev s’ouvrent aussi. S’il faut retrouver la vidéo d’un ancien projet sans empreinte, contrôlez le film avant de confirmer votre choix.

Sauvegarder et récupérer

Ctrl+S enregistre le projet à l’emplacement choisi. Vous pouvez enregistrer entre deux objets d’une même image. Chaque séance dispose aussi d’une copie automatique, y compris pendant le suivi automatique. Après une interruption, utilisez Fichier › Récupérer le travail précédent…. Si plusieurs copies sont proposées, repérez votre vidéo et la date de modification. Vérifiez le dernier point et enregistrez le projet dans votre dossier de travail.

Si MeVCine signale une erreur d’écriture, choisissez un dossier accessible et utilisez Enregistrer le projet… avant de fermer. Le dialogue de fermeture permet de revenir au projet avec Annuler.
