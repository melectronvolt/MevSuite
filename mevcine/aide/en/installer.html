Installing MeVCine

For teachers: a folder to copy or an installer on Windows, a package or an AppImage on Linux

The MeVCine folder (Windows)

On Windows, MeVCine comes as a folder (.zip archive), with no installation, to copy as it is (USB stick, shared folder, disk of each computer). It contains:

mevcine.exethe program, with the Qt libraries (the *.dll files and the platforms folder)
ffmpeg/the ffmpeg and ffprobe programs, which read the videos (including the HEVC of phones). Do not separate these files from the folder.
data/this guide (help)
COPYING.txt, NOTICE.txtthe licence

Installer (Windows)

MeVCine-version-windows-x64-setup.exe installs the same folder for all users in Program Files\MeVSuite\MeVCine, with a Start menu shortcut; it is uninstalled from the Windows Settings. Deployment on many computers (WAPT, GPO), with no window or question:

MeVCine-version-windows-x64-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /NORESTART

On Windows

Double-click on mevcine.exe. On first launch, Windows may show “Windows protected your PC”, because the program is not signed: More info, then Run anyway.

Display needs no graphics acceleration: MeVCine also works in a virtual machine or a remote desktop. If the window does not open, see Troubleshooting.

On Linux

  • Package: .deb for Ubuntu and Debian, .rpm for Fedora. It installs MeVCine in the applications menu, with ffmpeg (on Fedora, the ffmpeg of RPM Fusion decodes the H.264 and HEVC of phones; Fedora's own, ffmpeg-free, does not decode them all).
  • AppImage, with no installation: a single file, ffmpeg included, to make executable (right-click › Properties, or chmod +x) and then start.

A graphical desktop is needed (Wayland or X11). File dialogs are those of the desktop (GNOME, KDE…), and the desktop's dark theme is followed as long as the student has not chosen one.

On first launch

  • MeVCine uses the system language if it is French, otherwise English; and the light or dark theme of the desktop. The flag and the sun (or moon), at the top right of the window, change them; the choice is remembered.
  • The window opens at its normal size (1200 × 700, smaller if the screen is smaller), never maximised by itself; it then keeps the size the user gave it (and stays maximised if it was maximised).
  • MeVCine never reopens the last video: it only remembers the last video folder.

The command line

mevcine                        home screen: choice of mode
mevcine --simple fall.mp4      simple mode, with a video
mevcine --expert project.mevcine
mevcine -d 2 ...               debug messages (1 to 3) in the terminal

A shortcut to mevcine.exe --simple opens simple mode directly. A project (.mevcine, .cinemev, old .mecavideo) can also be given on the command line, or dropped onto the window. See Deploying MeVCine in a computer room.
